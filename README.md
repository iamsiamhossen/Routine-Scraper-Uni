# 📚 Routine Scraper – Smart Routine Management System

A web application designed to simplify class routine management for university students and faculty.  
This project was developed as part of **Project Development (Course Code: 3299)**, Department of Computer Science and Engineering, Khwaja Yunus Ali University.

---

## 🎯 Introduction
Routine Scraper is a smart routine management system that helps students and faculty easily search, view, and manage class schedules.  
It allows batch-wise routine search, free room checking, and department notice board integration to reduce confusion and improve academic time management.

---

## 🚀 Project Objectives
- Simplify class routine access for CSE students.
- Enable smart filtering by **Batch, Day, Time, Teacher, Room, Course**.
- Provide one-click **Free Room Checker** for spontaneous study sessions.
- Display important **Department Notices** (class changes, exam updates).

---

## ⚙️ Core Functional Features
- **Routine Search & Filtering** – Filter by batch, teacher, room, course, day, and time.  
- **Free Room Checker** – Instantly display available classrooms for current time slots.  
- **Department Notice Board** – Centralized section for academic updates.  

---

## 📋 Requirements

### Software
- **Frontend:** React.js, Tailwind CSS  
- **Backend:** Firebase  
- **Database:** Firebase Firestore  
- **Authentication:** Firebase Auth  

### Hardware
- Server with sufficient storage and processing power  
- User devices (desktop, mobile, tablet)

---

## 🏗️ Architecture
1. User visits the Routine Scraper web app.  
2. App queries Firestore database.  
3. Filters applied (batch, day, time, etc.).  
4. Returns clean and readable routine layout.
